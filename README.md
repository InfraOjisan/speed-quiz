## 📖 プロダクト概要

**「タイパ至上主義」の高校生・大学生・大人が脳汁を出して遊べる1分間タイムアタック学習ゲーム！**

ショート動画感覚の超高速テンポで問題をさばかせ、知らず知らずのうちに基礎固めと復習を行わせる新感覚のゲーミフィケーション学習アプリです。
スマホの片手操作（大型タップボタンまたはスワイプジェスチャー）に完全最適化されています。

## 🎮 主なゲームシステム・コアルール

### 1. 60秒タイムアタック＆超高速テンポ
- 制限時間は1プレイ「60秒」。
- **回答UI**: 画面下部の大型タップボタン（❌ NO / ⭕ YES）、または画面左右スワイプ。
- **正解時**: 即座にグリーンフラッシュ＋爽快なSE。次の問題がわずか**0.1秒**で高速表示！
- **不正解時**: **画面ヒビ割れ演出（ガラスクラッシュ）**＋端末バイブレーション＋ブザーSE＋**約2秒間の画面フリーズ・操作不能ペナルティ**。
- プレイ中は解説を一切出さず、テンポを最優先！

### 2. コンボ ＆ フィーバータイム
- **3連続正解**: コンボ発動（スコア1.5倍）。
- **5連続正解**: **フィーバータイム突入！**（BGM加速、サイバーネオン背景、残り時間＋2秒ボーナス、スコア2倍）。
- ミスした瞬間にコンボとフィーバーは即リセット。

### 3. 一発逆転！難問ボーナス（カットイン）
- 残り15秒以下になると、画面全体に**「⚠️ WARNING!! 緊急難問カットイン！」**の警報が発動！
- 灘中・開成中・筑駒中・桜蔭中などの難関校良問が強制カットイン。
- 正解すると**一挙1,000点＋激レア称号獲得**の大逆転チャンス！

## 🏆 リザルト画面 ＆ 診断・復習サイクル（4大ブロック）

1. **スコア＆アチーブメント（収集要素）**
   - 獲得スコア（SSS〜Cランク格付け）、最大コンボ数、正解率、平均解答秒数。
   - 20種類以上の二つ名称号・トロフィー獲得（『音速の思考』『逆転スナイパー』『リベンジの鬼』など）。
2. **AIパーソナリティ＆タイプ診断（＋動的アバター生成）**
   - 解答速度、正解率、ミス直後の焦り/硬直、得意科目などのテレメトリデータを分析。
   - 歴史上の人物（織田信長、坂本龍馬、諸葛亮孔明等）、芸能人、MBTI風コード、刺さる性格評を自動出力。
   - Canvasによるサイバーアバターバッジの動的生成＆画像保存・SNSシェア対応。
   - ※管理画面でGoogle Gemini APIキーを設定すれば、本物の最新LLMによる深層診断も可能！
3. **30秒リベンジデッキ（復習機能）**
   - 今回間違えた問題がカード形式でスタックされ、解説を確認可能。
   - ワンタップで**「ミス問だけの30秒復習マッチ」**が起動！正解すると「克服済み」ステータスとなり弱点DBからクリアされます。
4. **深掘りショートリンク**
   - 間違えた問題や難問のキーワードに応じたYouTube解説動画・Google検索への直行リンク。

## 📊 ダッシュボード ＆ 管理メニュー

- **ダッシュボード**:
  - プレイヤー名編集、獲得称号の装備・変更（「電光石火の求道者」など）。
  - 総得点、総プレイ回数、総合正解率。
  - 出題分類マスター進捗（「小学理科 18/20 90%完了」などのリアルタイムメーター）。
  - 全アチーブメント・トロフィーの一覧。
- **管理メニュー（お父さん・お母さんに設定してもらってね）**:
  - 生成AI APIアクセスポイント（Gemini API等）の設定。
  - 生成AI APIキーの設定（ブラウザ内LocalStorageのみに安全に保存）。
  - サウンド・BGM・バイブレーションのON/OFF切り替え。
  - 成績データ（学習記録・アチーブメント・弱点ノート）のCSV / JSONダウンロード。
  - ローカルデータの全消去・初期化。

## 💻 技術スタック・アーキテクチャ

- **フロントエンド**: HTML5, CSS3 (Modern CSS / Grid / Flexbox / CSS Variables), Vanilla JavaScript (ES Modules)
- **サウンドエンジン**: Web Audio API（外部音声アセットロード待ち不要、ゼロ遅延シンセ音源）
- **グラフィックス**: HTML5 Canvas（リアルタイムガラスクラッシュ描画、紙吹雪・スパークパーティクル、動的アバターバッジ描画）
- **オフライン・PWA**: Service Worker (`sw.js`) + Web App Manifest (`manifest.json`)
- **データ管理**: ブラウザ LocalStorage による学習進捗・弱点・アチーブメントの完全ローカル保存

## 🚀 ローカルでの動かし方

静的Webサーバーを起動するだけで、すぐにスマホやPCで動作します。

```bash
# Pythonの場合
python3 -m http.server 8080

# または Node.js (npx) の場合
npx serve .
```

ブラウザで `http://localhost:8080`（またはスマホから同一Wi-FiのローカルIP）にアクセスしてください。
